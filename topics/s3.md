# S3

## Description

S3 (Simple Storage Service) is an object storage protocol originally developed by Amazon Web Services. It has since become an industry-standard interface, with many self-hosted and cloud storage solutions offering S3-compatible APIs that allow the same tools and clients to work across different storage backends.

## AWS CLI

### Description

This details how to install and configure the AWS CLI for use with an S3-compatible endpoint.

### References

- [Installing or updating to the latest version of the AWS CLI](https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html)
- [Configuration and credential file settings in the AWS CLI](https://docs.aws.amazon.com/cli/latest/userguide/cli-configure-files.html)

### Install AWS CLI

This details how to install the AWS CLI on your system:

1. [Install](package-manager.md#install-software) the AWS CLI (v2) using your package manager, of which the package name varies:

   - Pacman/Yay: `aws-cli-v2`
   - Nix: `awscli2`

2. Verify the package is installed:

   ```sh
   aws --version
   ```

   Sample output:

   ```
      aws-cli/2.32.15 Python/3.13.3 Linux/6.14.6-arch1-1 exe/x86_64.ubuntu.22
   ```

### Configure AWS CLI Profile

This details how to configure a named profile for an S3-compatible endpoint:

1. Add a named profile for the S3 instance to `~/.aws/credentials`:

   ```ini
   [<profile-name>]
   aws_access_key_id = <access-key>
   aws_secret_access_key = <secret-key>
   ```

   The `<access-key>` and `<secret-key>` values are the credentials from your [S3 identity](#s3-identities).

   For example:

   ```ini
   [s3-admin]
   aws_access_key_id = c9a1f4d23e87b605a7c2e94f183d6a52
   aws_secret_access_key = 8e3b7d6c1a90f452b38e1c4d7a5f2e09
   ```

2. Add the corresponding profile configuration to `~/.aws/config`:

   ```ini
   [profile <profile-name>]
   region = <region>
   endpoint_url = <s3-endpoint-url>
   ```

   For example:

   ```ini
   [profile s3-admin]
   region = us-east-1
   endpoint_url = https://s3.example.com
   ```

   The `region` value is required by the AWS CLI but may be ignored where not applicable (i.e. self-hosted S3 implementations) - in such cases, any value would be accepted.

## Manage Buckets

### Description

> [!NOTE]
> This section requires the [AWS CLI](#aws-cli) to be [installed](#install-aws-cli) and [configured](#configure-aws-cli-profile).

This details how to manage S3 buckets on an S3-compatible endpoint. Bucket creation and deletion require administrative permissions on the identity.

### References

- [aws s3 ls](https://docs.aws.amazon.com/cli/latest/reference/s3/ls.html)
- [aws s3 mb](https://docs.aws.amazon.com/cli/latest/reference/s3/mb.html)
- [aws s3 rb](https://docs.aws.amazon.com/cli/latest/reference/s3/rb.html)

### List Buckets

This details how to list all buckets on an S3 instance:

```sh
aws s3 --profile <profile-name> ls
```

For example:

```sh
aws s3 --profile s3-admin ls
```

### Create a Bucket

This details how to create a bucket on an S3 instance:

```sh
aws s3 --profile <profile-name> mb s3://<bucket>
```

For example:

```sh
aws s3 --profile s3-admin mb s3://my-backups
```

### Delete a Bucket

This details how to delete a bucket from an S3 instance:

```sh
aws s3 --profile <profile-name> rb s3://<bucket>
```

To also delete all objects within the bucket, add the `--force` flag:

```sh
aws s3 --profile <profile-name> rb s3://<bucket> --force
```

For example:

```sh
aws s3 --profile s3-admin rb s3://my-backups
aws s3 --profile s3-admin rb s3://my-backups --force
```

## Manage Objects

### Description

> [!NOTE]
> This section requires the [AWS CLI](#aws-cli) to be [installed](#install-aws-cli) and [configured](#configure-aws-cli-profile).

This details how to manage objects in an S3 bucket.

### References

- [aws s3 ls](https://docs.aws.amazon.com/cli/latest/reference/s3/ls.html)
- [aws s3 cp](https://docs.aws.amazon.com/cli/latest/reference/s3/cp.html)
- [aws s3 rm](https://docs.aws.amazon.com/cli/latest/reference/s3/rm.html)
- [aws s3 sync](https://docs.aws.amazon.com/cli/latest/reference/s3/sync.html)

### List Objects

This details how to list objects in an S3 bucket:

```sh
aws s3 --profile <profile-name> ls s3://<bucket>
```

For example:

```sh
aws s3 --profile s3-client ls s3://my-backups
```

To recursively list all objects with a size summary:

```sh
aws s3 --profile <profile-name> ls s3://<bucket> --recursive --human-readable --summarize
```

For example:

```sh
aws s3 --profile s3-client ls s3://my-backups --recursive --human-readable --summarize
```

### Upload an Object

This details how to upload a file to an S3 bucket:

```sh
aws s3 --profile <profile-name> cp <local-file> s3://<bucket>/
```

**Alternatively**, to upload an entire directory:

```sh
aws s3 --profile <profile-name> cp <local-dir> s3://<bucket>/ --recursive
```

For example:

```sh
aws s3 --profile s3-client cp /home/myuser/data/file.txt s3://my-backups/
aws s3 --profile s3-client cp /home/myuser/data s3://my-backups/ --recursive
```

### Download an Object

This details how to download an object from an S3 bucket:

```sh
aws s3 --profile <profile-name> cp s3://<bucket>/<object> <local-dir>
```

**Alternatively**, to download all objects in a bucket:

```sh
aws s3 --profile <profile-name> cp s3://<bucket>/ <local-dir> --recursive
```

For example:

```sh
aws s3 --profile s3-client cp s3://my-backups/file.txt /home/myuser/data/
aws s3 --profile s3-client cp s3://my-backups/ /home/myuser/data --recursive
```

### Delete an Object

This details how to delete an object from an S3 bucket:

```sh
aws s3 --profile <profile-name> rm s3://<bucket>/<object>
```

**Alternatively**, to delete all objects in a bucket:

```sh
aws s3 --profile <profile-name> rm s3://<bucket>/ --recursive
```

For example:

```sh
aws s3 --profile s3-client rm s3://my-backups/file.txt
aws s3 --profile s3-client rm s3://my-backups/ --recursive
```

### Sync a Directory

This details how to sync a local directory with an S3 bucket.

To sync from a local directory to a bucket:

```sh
aws s3 --profile <profile-name> sync /local/dir s3://<bucket>/
```

**Alternatively**, to sync from a bucket to a local directory:

```sh
aws s3 --profile <profile-name> sync s3://<bucket>/ /local/dir
```

For example:

```sh
aws s3 --profile s3-client sync /home/myuser/data s3://my-backups/
aws s3 --profile s3-client sync s3://my-backups/ /home/myuser/data
```

Add `--delete` to remove files from the destination that no longer exist in the source, if you require both sides to be strictly identical.
